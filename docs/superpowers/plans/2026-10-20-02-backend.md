## Review Focus

Inputs the spec implies but never states (each is pinned by a test in the named task):

1. Email case: `Alice@X.com` registered, then `alice@x.com` register -> 409; login with any case works (Task 8, 9).
2. List params: invalid `sort` field -> 422 (never 500); `offset` past `total` -> empty `items` with correct `total`; `q` containing `%` or `_` matches literally (Task 4, 13).
3. Garbage credentials: malformed/empty refresh token, expired JWT, JWT with `type="refresh"`, `alg=none`, bad signature -> 401, never 500 (Task 5, 9, 10).
4. Concurrent refresh with the same token: exactly one succeeds, the other is treated as reuse (row lock `FOR UPDATE`) (Task 9).
5. Item ids: malformed UUID -> 422; unpublishing an item removes it from public list and detail (404) immediately (Task 13).

- Service (all `session` first, `settings: Settings` keyword):
  - `async def login(session, email, password, *, settings, require_admin: bool = False) -> Issued`: look up user; if missing run `verify_password(password, DUMMY_HASH)` and raise `Unauthorized`; wrong password or `is_active` false -> `Unauthorized` (identical detail "invalid credentials"); only after password verified, if `require_admin and role != admin` -> `Forbidden`.   - `async def refresh(session, raw_token: str, *, settings, require_admin: bool = False) -> Issued` algorithm:
    1. `h = hash_refresh_token(raw)`; `SELECT … WHERE token_hash=h FOR UPDATE`; none -> `Unauthorized`.
    2. `revoked_at is not None` -> REUSE: `UPDATE refresh_tokens SET revoked_at=now() WHERE family_id=:f AND revoked_at IS NULL`; **`await session.commit()`** (must persist before raising, since `get_session` rolls back on exceptions); raise `Unauthorized`.

    4. load user; if inactive, or `require_admin and role != admin` -> revoke family, commit, `Unauthorized`.
