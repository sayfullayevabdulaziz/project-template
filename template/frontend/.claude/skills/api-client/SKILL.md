# API client

`src/client/` is generated by `@hey-api/openapi-ts` from `openapi.json` (config: `openapi-ts.config.ts`). It is output only.

## Refresh after a backend change

- From the workspace root (the folder containing `backend/` and `frontend/`): `make sync-api` (exports the backend spec, copies it to `frontend/openapi.json`, runs `gen-api`).
- Or from this folder: `cp ../backend/openapi/admin.json openapi.json && make gen-api`.
- This repo alone has no `sync-api` target; the workspace `Makefile` provides it.
- `make check` at the workspace root fails with "stale client" if `openapi.json` differs from `backend/openapi/admin.json`.
- Review the generated diff. A renamed operationId breaks callers; fix them.

## Use it

- Queries: `fooListOptions({ query })` from `@/client/@tanstack/react-query.gen`, passed to `useQuery`.
- Mutations: spread `fooCreateMutation()` into `useMutation`, then add `onSuccess` and `onError`.
- Form limits: derive from `zFooCreate` in `@/client/zod.gen`.
- Types: `import type { ItemAdmin } from '@/client'`.
- After a write, `invalidateOp(qc, 'itemsList')` from `@/lib/query`. The id is the SDK operationId.

## Never

- Never edit files under `src/client/`. The next `make gen-api` overwrites them, and the format hook skips them.
- Never fetch with a raw `fetch` or a second client.
- Extend behavior in two places only:
  - `src/client-config.ts`: base URL from `src/env.ts`, `credentials: 'include'`.
  - `src/lib/auth.ts`: the access token (kept in memory only) and the 401 refresh-and-retry flow.
- Read env vars only through `src/env.ts`.
